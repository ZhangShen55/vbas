# 实施方案

拆出两段同步检测函数，保留原predict参数与结果整理；通过asyncio.to_thread并发提交，两分支全部收尾再返回或抛错。复用现有每模型RLock，不跨模型加全局锁。只并行同ROI双模型，多ROI仍按原实际顺序执行，避免扩大为ROI并行。GPU加载warmup既有行为不变。回退git旧提交完整发布；不删除历史模型/环境，不部署。

并发提交不代表不同模型GPU执行必然重叠。旧接口仍不经过BatchAdmissionController；默认线程池只限制同时执行线程，并非有界请求队列，高压待执行任务可能积压。本次不放宽或新增准入规则，不把原高并发容量与路数估算作为改后保证。
