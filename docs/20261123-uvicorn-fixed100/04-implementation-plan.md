# 实施方案

先CPU构造/校验确定100图输入及72唯一组合，固定代码/数据/Engine/配置指纹。独立私有驱动取得GPU锁及资源/端口守卫，复制配置，直接Popen Uvicorn main:app --workers1，所有Engine加载后Health成功及公开schema捕获；不使用scripts.benchmark.server。

控制器运行资源线程，角色覆盖管理/实际server/实际client。每接口30秒预热后顺序执行约定三轮，每组独立客户端子进程按固定100图和C有界闭环发送，保存结果/完整响应；父独立重算计数、序号和耗时。组间等待2秒。遇未知错误停止并保存。

无论成功/异常均finally仅终止本任务Popen服务/客户端并等待回收，记录端口关闭、GPU返回起点及源/其他环境未修改。随后离线重算72组、画耗时与吞吐/P95曲线，中文报告三轮范围/有限拐点，完整备份核验，更新05/07并提交推送perf、工作区干净。恢复仅从新run_id进行另行授权的新测试，不修改原件；本轮不部署。
