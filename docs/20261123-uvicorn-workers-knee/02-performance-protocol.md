# 协议（测前冻结）

完全复用uvicorn-fixed100-20261123-r1 plan选定的每接口100个不同图片ID、顺序及payload SHA，不重新抽样。main:app --workers 2/4/6三个独立阶段串行；每W每接口C1/2/4/8/16/32/50/100各3轮：升序、降序、seed20261118乱序；216组/21600正式请求。一请求一图、HTTP60、无重试、trace off、b512/q0不变。每组新客户端、max connections/keepalive=C，沿用单worker调度；C小于W时不强行分摊任务给所有worker，保留共享监听+keepalive实际分配。

每阶段必须看到W个实际GPU模型worker全部加载并完成应用启动；每接口正式前30秒HTTP C1预热，逐worker访问日志证明确实覆盖全部W。仅给Uvicorn现有日志加PID前缀，不添加API/推理中间件；正式每组日志逐PID计数与100条客户端响应核对，报告偏斜，不声称天然均匀。此日志格式相对历史W1多PID前缀，开销未做单独隔离，不据微小差异宣称显著收益。

主指标同旧W1：首发送任务启动至最后response body接收的100图makespan，不含模型加载/预热/客户端启动/输入预载，含HTTP连接与并发填充/排空。逐条HTTP/业务成功、序号/ID/耗时/失败链保存，三轮全100成功才参与推荐。失败组保留，未知HTTP/业务/非ReadError/ReadTimeout或严重CUDA/OOM/worker退出停下调查并关闭本阶段，不自动重跑或放宽服务。

每W每接口平台起点为三轮中位耗时在该W最优中位数105%以内的最小C。最终最快组合为W1/2/4/6所有三轮零失败点中中位耗时最短者；另给出距全局最优5%内优先更少W、再更小C的资源折中，二者分开。统一W按三个接口各100张等量顺序任务，求各接口在该W最快中位耗时之和最小；等量仅用于统一建议，非并发混合业务/SLO。边界/不单调/短任务分配/三轮波动限制如实列出，不无限补点。

每秒采样管理、Uvicorn父、所有worker、辅助和发生器PID CPU/RSS/GPU；保留阶段及每组绝对时间、worker访问分布和发生器process_time，短组样本少不当长稳资源。结束先确认进程/端口，再轮询最多30秒GPU内存/利用率连续空闲；保留全部退出样本，不因单次利用率残值误称服务仍运行。
